# NGO Research & Data Collection – NGOs Working in India

## Project Overview

This project presents a structured research and data collection exercise covering 10 NGOs working in India. The information was collected from the organizations' official websites and organized using Microsoft Excel.

The project was completed as **Task 1 of an AI Data Analytics Internship with InAmigos Foundation**.

## Project Objectives

* Research NGOs working in India using their official websites
* Collect relevant organizational information
* Organize the collected information into a structured dataset
* Identify key initiatives and areas of work
* Develop research insights based on the collected information

## Dataset

The dataset contains the following fields:

| Field           | Description                                                |
| --------------- | ---------------------------------------------------------- |
| NGO Name        | Name of the organization                                   |
| Website         | Official website of the organization                       |
| Area of Work    | Areas identified from the organization's website           |
| Headquarters    | Headquarters/location of the organization                  |
| Key Initiatives | Key initiatives identified from the organization's website |

## Research Insights

A separate **Research Insights** sheet was created to summarize observations from the collected dataset.

The research identified recurring themes such as:

* Education
* Health and nutrition
* Women's empowerment and livelihoods
* Child rights and protection
* Wildlife and environmental conservation
* Animal welfare
* Disaster response and community-focused approaches

These observations are based on the information collected from the 10 organizations and are not intended to replace the organizations' own terminology.

## Methodology

Information was collected from the official websites of all 10 NGOs.

Organization-specific terminology has been retained to accurately represent how each NGO describes its areas of work and initiatives.

The collected information was then organized and reviewed in Microsoft Excel.

## Tools Used
